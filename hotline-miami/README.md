# Hotline Miami

Este directorio prepara la versión web de Hotline Miami para servir bajo GitHub Pages dentro de `https://<usuario>.github.io/isekai-open-world/hotline-miami/`.

El juego original se toma del repositorio público conocido:
https://github.com/genizy/web-port/tree/main/hotline-miami

Se usa un loader local para mantener la ruta del subdirectorio del proyecto sin romper la configuración actual de Pages. Se pone la ejecución bajo control del navegador y se mantiene la lógica de touch compatible con iPhone.
